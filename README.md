# ずんだもん解説動画スキル（zundamon-metan-videos）

テーマを伝えるだけで、四国めたん（解説役）とずんだもん（聞き役）が掛け合いで解説する「ずんだもん解説」動画を Claude が作るスキルです。調査から台本、VOICEVOX の音声、字幕、MP4 の書き出し、サムネイル、YouTube の概要欄まで、Claude の中で完結します。

## できること

「〇〇をずんだもん解説して」と頼むと、次の順に進みます。

1. Web 検索でテーマを調べ、出典つきで事実を集める
2. 冒頭・本編（3〜5章）・まとめの構成で台本を書く（初期設定では、台本ができた時点で確認を求めます）
3. VOICEVOX でずんだもんと四国めたんの声を作り、字幕・解説パネル・立ち絵の口パクとまばたきを付けて MP4 に書き出す
4. 納品物として、次の5つを渡す

   * `video.mp4`：動画（初期設定は約3分）
   * `subtitles.srt`：字幕
   * `thumbnail.png`：サムネイル（1280×720）
   * `script.md`：台本
   * `description.txt`：概要欄（紹介文・チャプター・出典・クレジット）

## 動作環境

* Claude.ai または Claude のデスクトップ／モバイルアプリ（Free・Pro・Max・Team・Enterprise）
* 「設定 > 機能」で「コード実行とファイル作成」がオンになっていること
* コード実行のネットワークから github.com、pypi.org、archive.ubuntu.com に接続できること（VOICEVOX Core、Python ライブラリ、ffmpeg、日本語フォントを実行時にダウンロードします）

スクリプトは Linux（x86\_64）用です。Mac や Windows の Claude Code でそのまま動かすことは想定していません。

## 導入方法

1. このリポジトリの [Releases](../../releases) から `zundamon-metan-videos.zip` をダウンロードする（解凍しない）
2. Claude.ai で **Customize > Skills** を開く
3. 「+」→「+ Create skill」→「Upload a skill」を選び、ダウンロードした ZIP をアップロードする
4. 一覧に表示されたスキルがオンになっていることを確認する

## 立ち絵の準備（初回のみ）

立ち絵の画像は、素材の再配布にあたるためこのリポジトリには入っていません。坂本アヒルさんが配布している次の2つの素材を、各自でダウンロードしてください。

* 「ずんだもん立ち絵素材 2.3」：[https://www.pixiv.net/artworks/92641351](https://www.pixiv.net/artworks/92641351)
* 「四国めたん立ち絵素材 2.1」：[https://www.pixiv.net/artworks/92641379](https://www.pixiv.net/artworks/92641379)

初めて使うときに、この2つの ZIP をチャットに添付してください。スキルが表情ごとの立ち絵 54 枚を自動で作ります（約3分）。

作った立ち絵を ZIP で受け取り、自分用のスキルの `assets/img/` に入れてアップロードし直すと、次回からは添付が不要になります。その画像は自分で使うだけにして、ほかの人には配らないでください。

> 立ち絵を作るスクリプトは、上記の版のレイヤー名に合わせてあります。新しい版（V3 など）はレイヤー構成が違うため、そのままでは動きません。

## 使い方の例

```
南極の氷の下にある湖について、ずんだもん解説して
```

```
ずんだもんと四国めたんで、円安のしくみを5分の動画にして。一気に作って
```

動画の長さ、想定視聴者、台本の確認をするかどうかを指定できます。「一気に作って」と言うと、台本の確認を省きます。

## 利用規約とクレジット

作った動画を公開するときは、次の規約に従ってください。商用利用の条件などは、必ず各規約の原文を確認してください。

* [東北ずん子・ずんだもんプロジェクト キャラクター利用のガイドライン](https://zunko.jp/guideline.html)
* [VOICEVOX](https://voicevox.hiroshiba.jp/) の利用規約と、ずんだもん・四国めたんの音声ライブラリの利用規約
* 立ち絵素材（坂本アヒルさん）の ZIP に同梱の readme

動画のエンドカードと概要欄には、次のクレジットが自動で入ります。消さずに使ってください。

```
VOICEVOX:ずんだもん
VOICEVOX:四国めたん
立ち絵：坂本アヒル
```

キャラクターのイメージを大きく損なう内容、過激な内容、公序良俗に反する内容、特定の政治・宗教の主張には使わないでください。

## フォルダ構成

```
zundamon-metan-videos/
├── SKILL.md                  Claude が読む手順書
├── scripts/
│   ├── setup.sh              VOICEVOX Core・pyopenjtalk・ffmpeg・日本語フォントを入れる
│   ├── chars.py              立ち絵を読み込む
│   ├── render.py             音声・字幕・画面を作り、MP4 とサムネイルを書き出す
│   ├── finalize.py           台本と概要欄を作り、納品フォルダにそろえる
│   └── build\_psd\_sprites.py  配布元の PSD から立ち絵 PNG を作る
└── assets/
    └── README\_tachie.txt     立ち絵素材の入手先と利用条件
```
