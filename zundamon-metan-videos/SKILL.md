# ずんだもん解説の動画を作る（ずんだもん・四国めたん）

ユーザーが指定したテーマについて、四国めたん（解説役・画面左）とずんだもん（聞き役・画面右）が掛け合いで解説する「ずんだもん解説」の動画を作る。調査、台本、音声、字幕、MP4の書き出し、サムネイル、概要欄まで、すべてコードを実行できるこの環境で行う。立ち絵は assets/img に入っていればそれを使う。入っていなければ、手順0の3のとおり、配布元の立ち絵素材から作る。scripts フォルダの setup.sh、chars.py、render.py、finalize.py は動作確認済みなので、コピーしてそのまま使う。

## このスキルのフォルダ構成
- SKILL.md：この手順書
- scripts/setup.sh：VOICEVOX Core（ずんだもん・四国めたんの声）と、pyopenjtalk、ffmpeg、日本語フォントを入れる
- scripts/chars.py：立ち絵を読み込む
- scripts/render.py：音声・字幕・画面を作り、MP4とサムネイルを書き出す（--check で確認だけ）
- scripts/finalize.py：台本（script.md）と概要欄（description.txt）を作り、納品フォルダにそろえる
- scripts/build_psd_sprites.py：（予備）配布元のPSDから立ち絵を作り直す
- assets/img/：立ち絵PNG 54枚（坂本アヒルさんの立ち絵素材から作ったもの。5表情×口パク3段階×まばたき。komugi＝ずんだもん、azuki＝四国めたん）。公開版には入っていない（素材の再配布になるため）。各自が配布元の素材から作って入れる
- assets/README_tachie.txt：立ち絵の出どころと、配布元の readme（利用条件）

## 入力
- テーマ（必須）：わからなければユーザーに聞く。
- 動画の長さ：指定がなければ3分（±20%まで可）。
- 想定視聴者：指定がなければ、前提知識のない中学生〜大人。
- 台本の確認：指定がなければ「あり」（台本ができたら見せて、OKをもらってから動画にする）。「一気に作って」などと言われたら「なし」。
- キャラクターの役割は固定：四国めたんが解説役（画面左）、ずんだもんが聞き役（画面右）。毎回たずねない。

## 守ること
- 事実はWeb検索で確かめ、確かめられなかったことは台本に入れない。数字、年、人名、固有名詞には出典を残す。最近の出来事は、公式発表などの一次情報で確かめる。
- ネット上の画像、音楽、効果音は使わない。図やイラストはコードで描く。
- 立ち絵は assets/img の画像をそのまま使う。描き直したり、似せた絵を新しく描いたりしない。
- 東北ずん子・ずんだもんプロジェクトのキャラクター利用ガイドライン（https://zunko.jp/guideline.html ）、VOICEVOX の音声ライブラリの利用規約、立ち絵素材の約束（assets/README_tachie.txt。良識の範囲内で使う）に従う。
  - 動画のエンドカードと概要欄に「VOICEVOX:ずんだもん」「VOICEVOX:四国めたん」を必ず入れる（render.py と finalize.py が入れる）。立ち絵のクレジット（坂本アヒル）も入れる。
  - キャラクターのイメージを大きく損なう内容、過激な内容、公序良俗に反する内容、特定の政治・宗教の主張には使わない。賛否が分かれる話題は、両方の見方を紹介して中立にまとめる。
  - 立ち絵の画像そのもの（PNG・PSD）は成果物に入れない。
- 途中で問題が起きたら別の方法で解決して先へ進み、最後にまとめて報告する。

## 手順0：準備（1〜3分）
1. このスキルのフォルダ（スキルを読み込んだときに表示される「Base directory」）を SKILL_DIR とする。表示が見当たらなければ `find / -path /proc -prune -o -name render.py -path "*zundamon-metan-videos*" -print 2>/dev/null` で探す。
2. 作業フォルダを作り、スクリプトと立ち絵をコピーして、VOICEVOX を入れる。
```bash
mkdir -p zunda/img && cd zunda
cp "$SKILL_DIR"/scripts/* .
cp "$SKILL_DIR"/assets/img/*.png img/ 2>/dev/null; ls img | wc -l   # 54 になればよい。0 なら下の3へ
bash setup.sh                                               # 最後に「VOICEVOX の準備ができました」と出る
```
3. assets/img が見つからない、または54枚そろっていないときは、ユーザーに「ずんだもん立ち絵素材」と「四国めたん立ち絵素材」（坂本アヒルさんがニコニコ静画で配布しているZIP）の添付を頼む。添付されたら、`pip install -q --break-system-packages psd-tools` のあと `python3 build_psd_sprites.py ZIP1 ZIP2` で img/ に作る（約3分）。
   - build_psd_sprites.py は「ずんだもん立ち絵素材 2.3」「四国めたん立ち絵素材 2.1」のレイヤー名に合わせてある。「レイヤーが見つからない」と出たら素材の版が違うので、PSDのレイヤー名を一覧にして CFG の名前を直す。
   - 作り終えたら、次回から添付しなくて済むように、img/ の54枚をZIPにしてユーザーに渡してよいか聞く。渡すときは「自分用のスキルの assets/img/ に入れてアップロードし直せば、次から添付は不要。画像は再配布しないこと」と伝える。

## 手順1：調査
1. テーマについてWeb検索し、信頼できる情報源（公的機関、研究機関、大学、百科事典、大手メディア、当事者の公式発表など）を優先して事実を集める。
2. 視聴者が「へぇ」と思うポイントを3〜5個選び、それぞれの根拠と出典URLをメモする。
3. 説が分かれていることや、はっきりしていないことは、台本でもそのとおりに言う。

## 手順2：構成
- 冒頭（約15秒）：ずんだもんの疑問から入り、この動画で何がわかるかを予告する。
- 本編：章を3〜5個に分ける。1つの章で伝える要点は1つに絞る。
- まとめ（約20秒）：要点を3つでふり返る。
- 締め（約5秒）：締めのあいさつ。

## 手順3：台本
| | ずんだもん（聞き役・画面右、speaker は zunda） | 四国めたん（解説役・画面左、speaker は metan） |
|---|---|---|
| 見た目 | 緑の髪に枝豆の髪飾り、緑のサロペット | ピンクの長い髪（ツインドリル）、白いロリータ服 |
| 性格 | 好奇心が強く、視聴者が思いそうな疑問をそのまま口にする。驚いたり、こわがったり、調子に乗ったりする | 物知りで落ち着いたお嬢様。たとえ話でわかりやすく説明する |
| 口調 | 一人称「ボク」。「〜なのだ」「〜のだ」「〜なのだ？」「すごいのだ！」 | 一人称「わたくし」。「〜ですわ」「〜わよ」「〜かしら」「〜なの」 |
| 声 | VOICEVOX ずんだもん（ノーマル） | VOICEVOX 四国めたん（ノーマル） |

台本のルール
- セリフの中では「ずんだもん」「めたん」と呼び合う。
- 1つのセリフは全角35字以内（多くても40字）。長くなるときは分ける。
- 「ずんだもんの質問 → めたんの説明 → ずんだもんの反応」を基本の流れにし、3〜4セリフごとに、たとえ話、驚き、ツッコミ、クイズなどで変化をつける。
- 専門用語は、出てきたらすぐに説明する。
- 長さの目安は、1分あたり約390字（この設定の VOICEVOX の速さ）。
- 締めは、ずんだもんの「ご視聴ありがとうなのだ！」と、めたんの「また次の動画でお会いしましょう。」などで終える。

台本は作業フォルダに script.json として、次の形で保存する。セリフが多いときは、Python で辞書を組み立てて json.dump すると書きやすい。
```json
{
  "title": "動画タイトル（25字以内）",
  "thumbnail_text": "サムネイルの文字（読点で2行に分かれる）",
  "summary": "概要欄の紹介文（2〜4文。時点が大事な話題は「〇年〇月〇日時点の情報」と書く）",
  "colors": {"bg_top": [70, 90, 140], "bg_bottom": [200, 215, 235], "accent": [40, 55, 110], "line": [90, 120, 190]},
  "chapters": [{"id": 1, "title": "章の見出し"}],
  "lines": [
    {
      "speaker": "zunda",
      "text": "字幕に出す文",
      "yomi": "読み上げ用の文（読み間違えそうな語をひらがな・カタカナに直したもの。直す必要がなければ text と同じ）",
      "face": "normal",
      "chapter": 1,
      "panel": {"type": "bullets", "heading": "見出し", "items": ["項目1", "項目2"]}
    }
  ],
  "character_images": {"dir": "img"},
  "extra_credits": ["立ち絵：坂本アヒル"],
  "sources": [{"title": "出典名（日付）", "url": "https://..."}]
}
```
- colors：テーマに合う背景の色（上・下）、見出しの色（accent）、線の色（line）。字幕は白い文字に、ずんだもんは緑、めたんはピンクの縁取りになるので、背景は中くらいの明るさの色が見やすい。
- speaker：zunda（ずんだもん）か metan（四国めたん）。
- style（書かなくてよい）：そのセリフだけ声色を変える VOICEVOX のスタイルID。ずんだもんは 3 ノーマル、1 あまあま、7 ツンツン。めたんは 2 ノーマル、0 あまあま、6 ツンツン。多用しない。
- face：表情。話していないキャラは、最後に話したセリフの表情のままになる。
  - normal（ふつう）：ずんだもんは「ω」の口、めたんはほほえみ
  - smile（笑顔）：ずんだもんは目を細めて手を挙げる、めたんは目を閉じて手を差し出す
  - surprise（驚き）：ずんだもんは目が点、めたんは目を見開く
  - trouble（困り）：困り眉と汗。めたんは目をそらす
  - think（考え中）：ずんだもんはジト目であごに手、めたんは目をそらして口元に指
- chapter：chapters の id。
- panel：画面中央の解説パネルを切り替えるセリフにだけ書く。書かないセリフでは前のパネルをそのまま出す。最初のセリフには {"type": "title"} を付ける。
  - title：動画タイトル
  - heading：章の見出し（{"type": "heading", "heading": "…"}）。章の最初のセリフに付ける
  - bullets：見出しと箇条書き（3項目まで、1項目16字まで）
  - keyword：大きく見せる一語や数字と補足（{"type": "keyword", "keyword": "約700体", "sub": "補足の説明"}）
  - diagram：図（{"type": "diagram", "name": "関数名", "heading": "図の見出し", "spec": "何を描くか"}）。手順4で diagrams.py に描く関数を書く
- パネルの内容は、そのとき話しているセリフと合わせる（数字のキーワードは、その数字を言うセリフに付ける）。

「台本の確認：あり」のときは、ここで台本を「話し手／セリフ／パネル」の表（章の区切りも入れる）にしてユーザーに見せ、OKをもらってから次へ進む。話し手は「ずんだもん」「めたん」と書く。確認モード（手順5）を先に1回走らせて、読みと長さを直してから見せると手戻りが少ない。

## 手順4：図の準備（diagram パネルがあるときだけ）
script.json と同じフォルダに diagrams.py を作る。
```python
# diagrams.py の例
def scatter_bar(d, box, font):
    """d：ImageDraw、box：(x0, y0, x1, y1) 描いてよい範囲、font(size, black=False)：日本語フォント"""
    x0, y0, x1, y1 = box
    ...  # Pillow の図形と文字で描く。数値ラベルが見出しや枠からはみ出さないよう、box の中に収める

DIAGRAMS = {"scatter_bar": scatter_bar}
```
- パネルは横1320px×縦590pxで、左下と右下に立ち絵が少し重なる。図は box の中央寄りに描く。
- 曲線の矢印とラベルは重なりやすい。矢印は直線にして、ラベルは矢印の上か下に離して置くと崩れにくい。

## 手順5：確認モードで直す
`python3 render.py script.json out --check` を実行する（動画は作らず、2分ほどで終わる）。出力を見て直し、問題がなくなるまでくり返す。
1. 読み：[読みの確認] には VOICEVOX の読み（カタカナ。' はアクセント、/ は区切り、_ は無声化）が出る。1行ずつ見て、読み間違いは yomi のその語をひらがなに直す。
   - 英字や英語の社名・製品名はカタカナで書く（例：AI → エーアイ、OpenAI → オープンエーアイ、ChatGPT → チャットジーピーティー）。
   - 「今年」「昨年」は、動画が後で見られても正しいように、具体的な年にする。
   - 「〜側」は「〜のがわ」、「1つ目」は「ひとつめ」のように、誤読しやすい語を直す。数字は、数字のままのほうが自然に読まれることが多い（例：約14万回分）。
2. 長さ：[長さ] が目標から±20%より外れたら、台本を足したり削ったりする。
3. 字幕：[字幕の改行] で、48px 以下になったセリフや不自然な改行（「数／十件」のように語の途中で切れる）があれば、言い回しを変えるか、セリフを短くするか、2つに分ける。
4. [注意] に出たもの（文字が長すぎるパネル、関数のない図など）を直す。タイトルの「88pxまで縮小」は、2行に収まっていれば問題ない。
5. work/check.png（主な場面）と work/characters.png（全表情）を画像として開いて自分の目で見る。文字のはみ出しや重なり、図の崩れがあれば直す。

## 手順6：書き出す
`nohup python3 render.py script.json out > work/render.log 2>&1 &` でバックグラウンド実行し、work/render.log を見て「完了」と出るまで待つ（3分半の動画で約4分：音声合成に約2分、映像の書き出しに約2分半）。

out フォルダには video.mp4、subtitles.srt、thumbnail.png ができる。作業ファイルは ./work に置かれる（timeline.json、chapters.txt、check.png など）。

## 手順7：確かめる
- work/check.png と out/thumbnail.png を見て、確認モードのときと変わりないか、サムネイルの文字が立ち絵に隠れず読めるか確かめる。
- `ffprobe` で、映像と音声の両方があり、長さがそろっていることを確かめる。
- 台本の内容が、手順1で集めた出典と食い違っていないか見直す。

## 手順8：渡す
1. `python3 finalize.py script.json out /mnt/user-data/outputs/フォルダ名` を実行する（フォルダ名はテーマを表す短い英数字）。納品フォルダに次の5つがそろう。
   - video.mp4（動画）、subtitles.srt（字幕）、thumbnail.png（サムネイル、1280×720）
   - script.md（台本：開始時刻／話し手／セリフ）
   - description.txt（YouTube概要欄用：紹介文、チャプター、出典、クレジット）
2. 5つのファイルを SendUserFile でユーザーに渡す（スクリプトが書いたファイルなので、送らないとユーザーに見えない）。
3. 最後に、動画の長さ、章立て、途中で起きた問題とその対処を短く報告する。
